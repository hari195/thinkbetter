<br/>

A stochastic process is a random process that changes over time. In probability they are represented by a random variable. They are widely used as mathematical models to study and understand random processes. Some examples Stochastic processes have been used to explain random fluctuations in financial markets. Stochastic process can be classified as either continuous-time or discrete-time based on the state space within which the process is defined in. 

<br/>

<span class="inline-link">[Stochastic modelling](https://www.investopedia.com/terms/s/stochastic-modeling.asp#:~:text=Stochastic%20modeling%20is%20a%20form,different%20conditions%2C%20using%20random%20variables.)</span> is used to predict outcomes that account for certain levels of randomness. The models attempt to forecast variations in prices, returns etc. over time. Based on this, they are used to help make investment decisions. <span class="inline-link">[Monte Carlo Simulations](https://www.investopedia.com/terms/m/montecarlosimulation.asp)</span> are an example of a stochastic model.

<br/>

<span class="inline-link">[Markov process](https://www.randomservices.org/random/markov/index.html#:~:text=A%20Markov%20process%20is%20a,important%20classes%20of%20random%20processes)</span> is a random process in which the future in independent of the past given the present. This is another example of a stochastic proccess. And a chain of such events for a <span class="inline-link">[Markov Chain](https://en.wikipedia.org/wiki/Markov_chain)</span>. Any game that is entierly determined by a dice is an example of a Markov Chain.
